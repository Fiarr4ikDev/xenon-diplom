# Xenon Diplom — Микросервисная система управления складом и поставками  

🚀 *Учебный проект для изучения микросервисной архитектуры на базе Spring Boot и Spring Cloud*

---

## 💡 Описание

**Xenon Diplom** — это учебный микросервисный проект, реализованный с использованием современных Java-технологий. Он предназначен для управления складскими остатками, категориями товаров, деталями и поставщиками.

Этот проект был создан с акцентом на правильную архитектуру, чистый код и документирование. Он может служить отличной основой для дальнейшего расширения под реальные бизнес-задачи.

---

## 🧩 Архитектура

Проект состоит из 8 микросервисов, каждый из которых отвечает за свою функциональную зону:

| Сервис               | Назначение |
|----------------------|------------|
| `category-service`   | Управление категориями товаров |
| `part-service`       | Управление деталями |
| `inventory-service`  | Управление остатками на складе |
| `supplier-service`   | Управление поставщиками |
| `auth-service`       | Регистрация пользователей (в разработке) |
| `security-service`   | Базовая авторизация |
| `gateway-service`    | API Gateway с агрегацией Swagger |
| `eureka-server-service` | Реестр сервисов (Eureka Server) |

Все сервисы взаимодействуют через REST API, с возможностью расширения до использования очередей (Kafka/RabbitMQ).

## 🚀 Как запустить проект

1. Убедитесь, что установлены:
   - JDK 17+
   - PostgreSQL или MySQL
   - Maven

2. Настройте конфигурации БД в каждом сервисе (`application.yml`)

3. Запустите все сервисы по порядку:
   - `eureka-server-service`
   - `gateway-service`
   - Остальные микросервисы

4. Откройте документацию через Gateway:  
   [http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html)
